# Testo alternativo

PROJECT-02, Progetto di produzione completo. Quale controllo collega «Deployment» a «Documentazione» senza superare il limite dichiarato? La composizione rollback path collega «Deployment», «Documentazione». L'input è problema, dati, modello, eval, deployment e rollback; l'output è servizio versionato con metriche e piano di ritorno. Il limite esplicito è: un modello che passa un test offline non è automaticamente pronto in produzione.
