# Testo alternativo

MEMORY-02, Contesto lungo, retrieval e memoria. Quale controllo collega «Memoria episodica» a «Routing ibrido» senza superare il limite dichiarato? La composizione memory lifecycle collega «Memoria episodica», «Routing ibrido». L'input è segmento, query, budget e durata; l'output è contesto scelto, memoria aggiornata e costo. Il limite esplicito è: memoria persistente e contesto temporaneo hanno politiche diverse.
