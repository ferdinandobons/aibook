# Testo alternativo

MEMORY-01, Contesto lungo, retrieval e memoria. Come si passa da «Tre risorse differenti» a «Quando recuperare» mantenendo osservabile la decisione tra contesto, retrieval e memoria? La composizione memory layers collega «Tre risorse differenti», «Quando usare il contesto», «Quando recuperare». L'input è segmento, query, budget e durata; l'output è contesto scelto, memoria aggiornata e costo. Il limite esplicito è: memoria persistente e contesto temporaneo hanno politiche diverse.
