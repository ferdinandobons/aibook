# AI Book

Repository di lavoro per il libro **Intelligenza artificiale generativa**.

## Obiettivo

Costruire un manuale completo in italiano, dai fondamenti matematici ai modelli generativi, ai Transformer, alla multimodalità, al reasoning, agli agenti e ai sistemi di produzione.

## Metodo

- produzione seriale controllata, un capitolo completo alla volta;
- fonti primarie, technical report e documentazione ufficiale;
- spiegazioni progressive conformi a `docs/EXPLANATION_STYLE_AND_VISUALS.md`;
- esempi, formule, shape e codice introdotti nell’ordine didattico stabilito;
- immagini create con lo strumento immagini;
- revisione iterativa obbligatoria di ogni visuale prima dell’approvazione;
- nel repository entrano soltanto immagini finali approvate, accompagnate dal relativo `AUDIT.md`.

## Stato

Il capitolo pilota è **Capitolo 28. Il meccanismo di attention**. Lo stato aggiornato è registrato in `PROGRESS.md`.
